# C5 · 每型專屬插畫

本次由使用者糾正並明確要求 192 張：6 家族 × 16 標準 MBTI × 2 畫風。C3 的十二張中性造型不能算作矩陣完成。此階段保留 scoring／collector／Email gate，只更換展示取圖與匯出構圖。

唯一取圖鍵是 family + type + style。artFor 回傳該格已就緒的確切路徑，未知 type 或缺圖則 null。禁止跨型、跨家族、跨畫風 fallback；namespace 為 /art/mbti/{family}/{type}-{style}.png。舊來源檔名與來源記錄留在 ../art-incoming 及 docs/art-192/，前台只顯示新目錄。GPT 家族在產品中稱 Codex，同人適配說明保留。

正常流程不加入大圖庫。頁尾說明裡有 /art-gallery，提供 12 組（家族／畫風）各16張卡、完成數、獨立放大檢視與精確構圖描述。圖庫是目錄，不是使用者結果。每張卡的中央插畫以 contain 保留完整角色與主要道具；底部標題預留空間。PNG 使用相同取圖鍵與等比例置中框。

未定型用中性星芒，不用特定型別插圖；可以下載明示未知的中性卡。已定型但尚未製作插圖顯示缺圖狀態並停用插畫卡下載，保留真正的 assessment。主題與畫風切換只選展示，不重新測驗。

npm run verify:art 為嚴格完整性 gate：需要192格、192個唯一路徑、確認的 SHA256、192份不同的解碼像素，並檢查尺寸。任一缺圖或重複即 exit1，不能因 source file 改名或重新壓縮同圖而通過。--allow-pending 只供開發進度檢查，不可當完整交付。人工構圖 QA 另外確認圖中主要道具、動作及構圖差異；雜湊不同本身不證明視覺差異。
