# 單次授權與真實等待

正常路徑：網站建立 30 分鐘會話 → Agent 讀公開協定 → 一次確認本人來源、期間、最小欄位與精確目的地 → 需要時走主機必要核准 → 本機分析 → 嚴格驗證 → 相同 JSON／key 有界重試 → 網站輪詢自動揭曉。

必要分支：範圍變更重新確認；真正主機待核准暫停；網路不通明示未知；提交已接受但回應遺失原 key 重試；到期不續期、保留不含權杖的本機最小摘要；換新會話後明確授權新目的地。沒有保留摘要才在新授權後重新分析。

狀態資料沒有百分比、任務內容或自由文字。seq 並非心跳，重送不刷新 updatedAt；新 seq 只在實際階段改變時產生。超過 90 秒不保證仍在工作。完成依實際存入報告，不接受客戶端 complete。

Email 是網站決定完整報告權限的必要選項；收藏卡可不填。選填 Email 不代表網站已經寄信。此版本無任何寄信動作。

前台只保留一個主要動作。詳細指令、等待協助、觀察依據收在可展開內容。這次新增的範圍卡與等待狀態沿用既有留白、字體、薰衣草底色與淺綠主按鈕，不改分型或圖庫。
