# C6 五語系

使用者要求 zh-TW、zh-CN、ja、ko、en。瀏覽器偏好決定第一次顯示；頁尾可隨時選語言並記在 localStorage，重整保留。資料、授權、分型與192格插畫不因語言重算，暱稱、程式碼、網址、專有名稱保持原值。HTML lang、字型、數字與時間顯示跟隨選擇。

翻譯範圍包含單一焦點流程、Email用途、完整報告、未知與證據缺口、等待與復原、錯誤、一次授權collector指令及規則、圖片署名和PNG。翻譯在本專案製作，不使用外部翻譯服務。API協定與列舉維持原碼；語言切換不保存或暴露會話寫入權杖。

PNG先等待字型就緒並使用語系適用的系統字型，長文字量測縮放。下載檔名含語系、原碼畫風與當地語言的「角色卡」名稱；不含Email、權杖、會話ID或私人紀錄。正式驗證包括5語言瀏覽器預設、手動選擇持續、行動版溢出、prompt安全規則、收件和report gate、未知／重試／到期、PNG實際字型及每語言一般／Q版／暱稱卡共15份下載圖片。
