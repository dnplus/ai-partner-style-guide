# 你的 Agent MBTI · C3

本人在 Air 的本機瀏覽器，替 Agent 命名，選擇是否提供結果用途 Email，複製專屬指令。Agent 先取得本機分析授權，再預覽最小摘要並取得提交授權。網站收件後揭曉工作風格，完整報告僅在提供 Email 時開放；未提供則只有卡片。一般／Q 版與六個主題使用同一份觀察。下載不含使用統計、Email 或會話權限。

維持 C2 單一焦點逐步畫面、上一頁、等待／重試／到期復原、觸控及鍵盤旋轉。不加入一般人格問卷、不新增角色、不部署、不讀真實私人紀錄。

「你怎麼帶它做事，它就長出怎樣的工作風格。」以主人要求與 Agent 可觀察的合作行為描述這段期間，不推斷人的人格，也不宣稱模型具有固定性格。借用 E/I、S/N、T/F、J/P 字母，這是自訂的娛樂性觀察規則，非官方 MBTI 評量。16 個中文稱號及文案為本專案原創。

| 軸 | 一端 | 另一端 | 不可使用的捷徑 |
|---|---|---|---|
| E/I | 互動共創：在可獨立處理時，仍以可見選擇共同塑造結果 | 整理後交付：先完成可見整理，再帶著整合結果回報 | 必要授權、澄清阻塞、訊息數、內在思考 |
| S/N | 具體起步：先以現有事實、實例與限制界定問題 | 可能性起步：先用模式、替代假設與跨情境連結開展問題 | 幻覺、是否查資料、是否使用工具 |
| T/F | 準則取捨：合理方案衝突時，依一致的比較標準決定 | 情境取捨：合理方案衝突時，優先受影響者的需求、價值與處境 | 禮貌用語、冷淡語氣、做不做正確查核 |
| J/P | 路線先行：在仍可保留選項時，先約定路線與里程碑 | 試探收斂：保留可行選項，透過可逆的小實驗再決定 | 不可靠、失敗重試、拖延、強制工作流程 |

每筆觀察分開記錄 ownerRequest 和實際 behavior，且須有兩端皆可行的 opportunity。主人要求本身不能當作已發生行為。已知要求與實際行為相反、平台限制、工具故障或必要授權不計入偏好。看不到主人要求時保留 unknown；沒有指定方向用 not_specified。

一個獨立使用者目標是一個 task。多輪、子任務、同一工作的重試不能拆成多個 task。同一 task 同一軸重複觀察只算一次；兩端皆出現計為 mixed。每軸勝方至少獲得三個獨立有效 task 支持，且勝方佔所有有效 task（含 mixed）至少三分之二，且兩端相差至少兩個 task，才選一端。這些是避免輕率定型的內部啟發式門檻，不是心理測量信度、準確率或特質強度。整體 coverage 為 insufficient 時全部保留未知。網站只能校驗摘要的一致性，不能驗證未收到的原始紀錄。

完整結果只使用 16 個標準代碼；任一軸未知則 type:null，保留內部 pattern 與逐軸原因，卡片顯示「未定型」。報告提供下一個值得觀察的真實工作情境，不用假想問卷補齊。日期、工具來源、情境、缺口、用量放在報告展開區。

v2 移除舊等級、四軸與訊號。新樣本為三個獨立任務的原創 INTJ 工作風格示範，不是舊分型轉換。資料庫保留舊列，以 protocol_version 區分；舊會話需要重新觀察，授權讀寫回傳 410，授權刪除仍可用。不將舊結果靜默轉換。客戶端使用新的 sessionStorage 命名空間。
