# 你的 Agent MBTI · C3

本人在瀏覽器替 Agent 命名、通過 Turnstile，複製專屬指令。Agent 先取得本機分析授權，再預覽最小摘要並取得提交授權。網站收件後揭曉工作風格與完整報告，只有建立連結的瀏覽器能讀取。一般／Q 版與六個主題使用同一份觀察。下載不含使用統計或會話權限。

維持 C2 單一焦點逐步畫面、上一頁、等待／重試／到期復原、觸控及鍵盤旋轉。不加入一般人格問卷、不新增角色、不部署、不讀真實私人紀錄。

「你怎麼帶它做事，它就長出怎樣的工作風格。」`agent-workstyle-v2` 只看使用者自己的訊息，判斷人怎麼帶 Agent，不看 Agent 的習慣，也不推斷人的人格。借用 E/I、S/N、T/F、J/P 字母，這是自訂的娛樂性觀察規則，非官方 MBTI 評量。16 個中文稱號及文案為本專案原創。

| 軸 | 一端 | 另一端 |
|---|---|---|
| E/I | 途中掌舵：看中間結果後改方向、範圍或優先順序 | 開場定調：目標、脈絡、限制或完成標準先講清楚，之後少插手 |
| S/N | 給做法：檔案、步驟、指令、工具、輸出格式、範例 | 給方向：目標、意圖、方向，路線交給 Agent |
| T/F | 看證據：以測試、數字、規格、差異、來源、規則驗收或修正 | 看感受：以手感、品味、受眾、語氣或人的體驗驗收或修正 |
| J/P | 有章法：有里程碑的計畫、固定流程、可重用資產，或呼叫既有資產 | 隨手試：探索、嘗試、邊做邊調、一次性使用 |

提示長短、輪數、術語、核准、「繼續」、沒有判斷的錯誤貼上、注入的系統文字都不算證據。T/F 在使用者從未驗收、修正或選擇時為 unclear。

一個獨立使用者目標是一個 task。每個 task 每軸強迫選較重的一邊，或在使用者訊息完全沒有可比較的線索時選 unclear。伺服器每軸只數非 unclear 的選擇：少於 3 個或打平為 `?`；多數勝出，勝方 ×3 ≥ 總數 ×2 且差至少 2 為 clear，其餘為 lean。整體 coverage 為 insufficient、或來源 unknown 的 task 不計。這些是內部啟發式門檻，不是心理測量信度、準確率或特質強度，介面不顯示百分比或次數。

四軸都有結果（clear 或 lean）才輸出 16 型代碼；卡面以淡色標示 lean 字母，`?` 只留給未定的軸。使用者可在揭曉前選填「你覺得自己是哪一型？」；它與摘要分開存放，從不進入計分，只用來在揭曉、卡面與分享文字產生「你以為你是 INTJ，帶 Agent 時是 ESTP」的對照。卡面插畫依實測類型選配。

v2 移除舊等級、四軸與訊號。新樣本為三個獨立任務的原創 INTJ 工作風格示範，不是舊分型轉換。資料庫保留舊列，以 protocol_version 區分；舊會話需要重新觀察，授權讀寫回傳 410，授權刪除仍可用。不將舊結果靜默轉換。客戶端使用新的 sessionStorage 命名空間。

現有十二張圖片改以中性 portrait 檔名使用，保留來源與授權。任何分型都能選任意主題與畫風；造型不決定分型，也不暗示存在每型專屬畫。

字母來源僅參照 [Myers & Briggs Foundation 四組偏好](https://www.myersbriggs.org/my-mbti-personality-type/the-mbti-preferences/) 與 [16 個標準代碼](https://www.myersbriggs.org/my-mbti-personality-type/the-16-mbti-personality-types/) 的命名。上述 Agent 行為類比、評估方式、門檻與中文描述均為本專案自訂，未使用官方量表、題目或計分。
