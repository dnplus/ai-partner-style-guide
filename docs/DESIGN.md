# AI 人物誌 — 視覺與產品規格

本機規格圖：design-concept.png，1536×1024。以已提供的 Library 龍娘素材與已檢視的 holo 3D 截圖產生 UI 概念，沒有新增角色設計。工具：內建 image_gen。原始生成記錄留在此 task。

色彩：背景 #f5f3fa，文字 #18151f，紫色 #7448ed，主按鈕 #dcfc79，邊線 #d9d0ed。中文字體 PingFang TC / Noto Sans TC 系統後備；卡面 PVSE 與 CODEX 使用 serif。標題 80–84px desktop / 約 42px mobile。圓角：卡片25、dialog24、按鈕100px。間距以8px階為主。

首屏：精簡頂部導覽，左側三行標題＋說明＋召喚／示範，右側可拖曳黑色實體卡；下方雙風格切換與操作提示。三步驟橫向流程在手機疊放。所有文字與操作皆為 HTML。

允許的首屏文字：AI 人物誌、誕生流程、16 型圖鑑、關於這份觀察、非商業同人企劃；你怎麼用 AI，就有什麼，專屬形態。從真實使用習慣，召喚你的 AI 角色卡。六個等級、十六種風格，每一次進化都有跡可循。召喚我的角色、先看示範、紀錄留在本機 · 只回傳你確認的摘要；CODEX／示範卡／PVSE／系統建築師／LV 4+／示範旅人；一般／Q 版／拖曳卡片，看看另一道光。流程標題沿概念，副文因授權、摘要與PNG實際行為精確化。無 hero eyebrow。

狀態：建立表單 → 等待與專屬指令 → 結果頁；沿用相同背景、字體、按鈕。結果頁顯示樣本類型、暱稱、等級、四軸、期間、覆蓋與缺口、模型家族／客戶端，提供PNG與暱稱模式。錯誤、失效與刪除有實際狀態。

圖鑑是首屏以下的擴充面板：6家族 ×16類型 ×2畫風，六個家族各有 PVSE 一般／Q 版，共 12 張圖準備完成；其他圖不冒用既有角色圖。切換圖鑑不變更評估。

卡片使用 CSS 3D perspective、獨立背景／前景／文字層、mask 選擇性虹彩、光澤、9px假厚度与陰影。一般和Q版共享同一個元件。素材是合併前景，沒有假稱翅膀等已獨立分層。無須 Three.js 即能提供所要求效果；參考原作技術未核實。

尊重 prefers-reduced-motion，停用旋轉與動態反射。鍵盤方向鍵旋轉，Home 回正，焦點可見。手機拖曳只占卡片區，其他區可捲動。

PNG 為1080×1620靜態分享卡，含素材署名、CC授權與風格免責；不含 Email、token、會話ID、原始紀錄或指標。暱稱模式隱藏等級與分型。動畫匯出留待後續評估，不阻擋本輪核心流程。
