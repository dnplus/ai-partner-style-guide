# C2 視覺與互動驗證

本輪依 `guided-cover.png`、`guided-identity.png`、`guided-waiting.png` 三張新概念實作；它們與最終建置的 1536×1024 Chrome 截圖均已用 view_image 實際檢視。手機另以 390×844、觸控環境操作。所有畫面與表單以 HTML/CSS 呈現；沒有把生成圖當整頁背景，也沒有替換既有角色臉。

| 對照 | 最終結果 |
| --- | --- |
| 首頁 | 置中襯線兩行標題、單張浮動卡、唯一主操作「開始觀察」。只有頁尾另有「關於」；自動測試確認可見按鈕共兩個。沒有 demo、圖鑑、報告、設定或說明集群。 |
| 身分 | 小角色、暱稱、折疊 Email、主要按鈕。返回保留內容；有既存會話不重建。焦點以紫色底線顯示。 |
| 等待 | 封存卡背、真實 pending 狀態、有效期限。網站不宣稱知道 Agent 正在讀取或分析；沒有假的百分比。失聯只顯示重試，到期提供恢復路徑。 |
| 揭曉 | 角色與同一份評估是主體。Email 決定下一步是報告或收藏。虛構資料一直明示。 |
| 收藏 | 此時才出現畫風與卡片選項；沒有重測。預設暱稱模式，PNG不含 Email、用量、會話 ID、權杖。 |
| 卡片 | CSS 3D 保留卡厚、陰影、獨立角色／文字深度、角度虹彩與選擇性 foil；hover、觸控拖曳、方向鍵都觀察到變化。角色是完整透明前景，不假稱已把頭髮／手腳分開建模。 |
| 手機 | 修正裝飾光暈造成的 27px 溢出；最終 document scrollWidth ≤390。主操作在可讀位置，卡面與一般／Q 版操作可用。 |
| 減少動態 | 停止浮動、翻轉及反射變化；同一套卡面、鍵盤操作與 PNG 仍可用。 |
| 匯出 | 實際下載 1080×1620 PNG，檢視一般完整卡與 Q 版暱稱卡；署名、同人、CC BY-NC-SA 4.0 及示範標記保留。 |

有意差異：卡面沿用12張已驗證資產，因此不逐像素複製概念圖中的二次生成角色；裝飾線採較簡潔的可運算樣式；表單與等待頁以實際產品文案補充必要的 Email／本機狀態。概念圖的假倒數不作為實際進度。

原始 holographic 效果參考仍為已落地檢視的 Library `libfile_8f1ef2526f8881919b4619ac9ac793be`，SHA-256 `7da939c01d2110bb623f0c38640f7d36920dda613fcf57d40147e3e1b953641f`。來源使用什麼技術未確認；這個網站使用 CSS 3D，沒有聲稱使用或複製來源的 Three.js 實作。
