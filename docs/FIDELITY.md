# 視覺驗證紀錄

概念：`docs/design-concept.png`（1536 × 1024）。實作：`evidence/desktop-home.png`（相同原生 viewport）；另檢查表單、結果一般／Q 版、手機 390 × 844、reduced motion、六家族與三個下載 PNG。概念與實作均透過 view_image 實際檢視，未以文字或縮圖代替。

| 對照項目 | 觀察與處理 |
| --- | --- |
| 首屏結構 | 維持上方細導覽、左三行大標／CTA、右浮動黑卡、下方三步驟。沒有額外 hero eyebrow。 |
| 色彩 | 保留淡紫白底、深墨標題、紫色重點、萊姆綠主按鈕；細字加深，維持可讀性。 |
| 排版 | 同樣三行標題與中英混排；採本機 PingFang TC 系統字而非生成圖內不可驗證字型，因此字重／字寬不是逐像素重製。 |
| 卡片 | 實體圓角、細虹彩邊、柔陰影、厚度及角度變化可見。移除會把子層壓平的父層 filter；用厚度層陰影保留 3D 深度。 |
| 插圖 | 保留已收到的實際全身 PNG，與概念中的放大裁切不同。沒有把概念圖重新生成的臉當正式素材，也沒有假稱肢體已拆層。 |
| 互動 | 一般／Q 版及六家族切換不重測、不改結果；等待圖片 decode 後截圖，避免截到前一張載入中的暫態。 |
| 手機 | 390 × 844 無橫向溢出，卡片觸控拖曳實測，表單在視窗內；桌面三步驟變直排。 |
| 降低動態 | reduced-motion 不旋轉，不移動反射，角色圖與下載仍可用。 |
| 匯出 | 實際 PNG 1080 × 1620，清晰可读；暱稱版無級別／分型／Email／會話 ID／token。署名、授權及示範標示保留。 |

文案差異：首屏主標／兩個 CTA 與概念一致；三步驟副文改為實際「先授權閱讀、再確認摘要、最後 PNG」流程。加入必要的虛構示範標示、圖鑑製作進度與非心理測驗說明。結果頁使用真實 callback 回傳的欄位，不填充杜撰真人資料。

有意差異：卡片不遮住頂部導覽；原生瀏覽器中文字型與生成圖不同；原始全身資產比概念肖像裁切留白較多；下載為獨立靜態卡面而非擷取透視後的 UI。這些差異保留閱讀、觸控與已交付素材的一致性。
