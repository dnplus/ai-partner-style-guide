# 你的 Agent MBTI · 角色素材與授權

本圖庫以六個家族 × 16 個標準四字母代碼 × 一般／Q 版為目標，共 192 格。每格使用不同的完整插畫，不以同一張圖片換文字、顏色或背景補齊。已接入 157 張經核對的既有素材及 35 張新製作插畫，共 192 張。網站顯示實際完成數；缺圖不使用其他型的插畫。

插畫依實際道具、動作與構圖選配，與 MBTI 評分完全獨立。這不是舊分類與新字母的對應，也不表示原作者以本網站分類創作或認可本產品。未知評估使用中性卡面，不補猜一型。來源的歷史檔名與署名保留於本機來源紀錄，不作為分型依據。

## 本機驗收

[插畫圖庫](/art-gallery) 可切換家族與畫風，放大檢查每型的道具及完整構圖。卡片與 PNG 皆使用 contain 比例，不裁掉主要物件。前景為合併 RGBA 圖片，沒有宣稱頭髮、衣裙、翅膀已逐層分離。

來源選圖與原始署名文件保留於專案 docs/art-192/。lib/art-manifest.json 決定唯一的家族／代碼／畫風取圖；`npm run verify:art` 檢查實際本機檔案雜湊、解碼像素雜湊與完整性。檢查會拒絕重複圖或以缺圖冒充完成。早期的十二張中性造型檔案保留供歷史追溯，已不作為結果替代圖。
